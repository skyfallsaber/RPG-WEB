REGRA FUNDAMENTAL DO PROJETO



O RPG deve possuir uma arquitetura modular, organizada e orientada a dados.



Cada funcionalidade deve possuir seu próprio módulo e responsabilidade.



A lógica do jogo deve ser separada do conteúdo do jogo.



Novos monstros, habilidades, classes, itens, NPCs, cidades, masmorras, eventos e outros conteúdos devem ser adicionados preferencialmente por meio de novos arquivos dentro das respectivas pastas.



Não criar arquivos centrais gigantes.



Não misturar sistemas independentes.



Não colocar todo o conteúdo do jogo em um único arquivo.



Sempre que possível, uma nova funcionalidade deve ser adicionada como um novo módulo sem alterar sistemas existentes.



Alterar sistemas existentes somente quando a nova funcionalidade realmente exigir uma alteração na regra daquele sistema.



A estrutura deve permanecer escalável para que o projeto possa crescer de dezenas para milhares de conteúdos sem perder organização.
